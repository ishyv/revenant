The fixed 1024x1024 R8 atlas is rasterized during the graphics crate build with
fontdue at 18 pixels and packaged in the application. It covers Unicode scalar
values 32..383 (inclusive), with `?` for unsupported characters. Labels use linear
sampling and scale through the world-to-physical-pixel camera transform; there is
no per-surface runtime font rasterization or font download. The original font and
OFL notice remain bundled unchanged. Application text outside the native viewport
is independent of this deliberately bounded atlas.
