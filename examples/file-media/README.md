# File & media desktop example

Run `revenant dev` here with Revenant 0.3. `revenant build` packages a native
Tauri app; `web/` is a static SvelteKit SPA, not a production server. The hidden
`.revenant/desktop` bootstrap and SDK snapshot are generated by the CLI.
The CLI adds Zed linked projects for the native library and hidden host while
preserving existing project settings and comments.

`native/src/lib.rs` exports `app() -> revenant::Application`. It adds only the
handwritten `records.normalize` operation. Built-in `files.checksum` and
`media.readMetadata` are registered automatically; duplicating their IDs fails
contract composition. There is no application Tokio main, registry/export glue,
WASM target or native server feature.

The main page uses `app.files.openFolder()` to obtain a scoped native `Folder`,
then `folder.files()` to create an indexed query. Search and sorting happen over
the native dataset. `CollectionView` from `@revenant/client/ui` virtualizes the
view and requests bounded metadata windows; the UI never materializes a full
scan or file contents just to select all. Explicit selection is bounded; use
`library.selection().allMatching().run(app.files.checksum)` for every matching file. The host waits
for scan completion and freezes native batch input.

A `Task<BatchResult<Output>>` projects native progress, cancellation and terminal
state. `BatchResult.page(offset, limit)` loads bounded outcomes. Cancelled or
failed tasks retain available results through `task.results(...)`; disposal
releases them. This app renders 64 results at a time and preserves partial
outcomes rather than treating cancellation as success.

Native settings store query preferences under the configured application ID.
Native previews own leased resources and host-formatted URLs. A new preview
releases the previous one; route teardown disposes the child application scope,
including views, tasks, selections and preview tokens. The root app is provided
once in the layout. Each page uses `useApp().createScope()`. Each chosen folder
gets a further child scope; replacing it releases the old native folder token,
views and retained results. Cancelling the picker disposes the unused scope.

The records page illustrates a small local collection with typed native calls.
Its DTO and Rustdoc live in `native/src/records.rs`. Contract extraction runs the
compiled host with `--revenant-contract` before any window starts; the generated
facade exposes `RecordsNormalize.Input`, `RecordsNormalize.Output`, JSDoc and a
link to the Rust definition. A failed rebuild retains the previous facade.

Prerequisites and packaging: [Tauri 2 prerequisites](https://v2.tauri.app/start/prerequisites/).
Windows installers use NSIS and bundle the offline WebView2 installer.
